# Evaluation of Enhanced Search: Pre vs Post Feature

This repository contains two projects demonstrating a basic search (Project A) and an enhanced search (Project B) with tests and scripts to compare them.

Folders:
- Project_A_PreFeature_Search: Basic keyword search.
- Project_B_PostFeature_Search: Enhanced search with TF-IDF, fuzzy matching, suggestions and recommendations.

Run instructions:
- Ensure Python 3.10+ is installed.
- Run `bash run_all.sh` to run all tests and generate a report.

See `compare_report.md` for the results.
