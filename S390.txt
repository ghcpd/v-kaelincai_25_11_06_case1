## Key Implementation Notes
- Project A: Basic keyword matching. Score = count of tokens matched in name+description.
- Project B: Enhanced search:
  - TF-IDF cosine similarity (scikit-learn TfidfVectorizer).
  - RapidFuzz fuzzy token matching.
  - Combined score = 0.6*tfidf + 0.4*fuzzy.
  - Recommendations: top product -> products with shared tags or category.
  - /suggest endpoint: query prefix-based suggestions.
