# Evaluation of Enhanced Search Feature

This workspace contains two Python projects demonstrating a pre-feature basic search (Project A) and a post-feature enhanced search (Project B). Each project includes source code, a small Flask server, tests, and scripts to run the tests and collect simple metrics.

Folders:
- Project_A_PreFeature_Search: basic keyword search
- Project_B_PostFeature_Search: enhanced search with fuzzy matching, suggestions, and related recommendations

Top-level scripts:
- run_all.sh — sets up both projects, runs tests, and writes a compare report

See each project's `setup.sh` and `run_tests.sh` for details.
