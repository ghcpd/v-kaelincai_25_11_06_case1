# Project A — Pre-Feature Basic Search

This project implements a basic keyword-based search:
- Case-insensitive substring matching across product name, description, and tags.

Setup:
1. cd Project_A_PreFeature_Search
2. ./setup.sh (or use PowerShell to create venv and pip install -r requirements.txt)
3. Run tests: ./run_tests.sh

Output:
- results/results_pre.json
- logs/log_pre.txt

Limitations:
- No fuzzy matching, suggestions, or recommendations
- Cannot handle typos
